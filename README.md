This repository will contain the code and configuration files for the TSD 2025 paper ["An Exploration of ECAPA-TDNN and x-vector Speaker Representations in Zero-shot Multi-speaker TTS"](https://doi.org/10.1007/978-3-032-02548-7_8) (arXiv version [here](https://arxiv.org/abs/2506.20190)).

Based on an older version of [jmaty/Coqui-TTS](https://github.com/jmaty/Coqui-TTS) (from November 2, 2023), which is itself a slightly modified fork of [coqui-ai/TTS](https://github.com/coqui-ai/TTS).

(Currently, the repository only contains the base code from jmaty/Coqui-TTS (from [this](https://github.com/jmaty/Coqui-TTS/tree/d5376545392fddfb3705663fe02c2dd861408df3) revision). The modified version that was used in the paper will be added in the following commits, to make it easier to view the changes.)
